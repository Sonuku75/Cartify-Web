# Engineering Development Standards

This directory establishes developer workflows, coding standards, and tooling expectations across the Cartify repository.

## Standards
- **Branching**: Trunk-based development or short-lived feature branches (`feat/`, `fix/`, `chore/`).
- **Code Style**:
  - Python: PEP 8 compliant, type-annotated where applicable.
  - TypeScript: Strict TypeScript, ESLint, Prettier formatting.
- **Testing**: Every PR must include automated test coverage for new functionality or bugfixes.
- **Commit Messages**: Conventional commits (`feat: ...`, `fix: ...`, `docs: ...`).
